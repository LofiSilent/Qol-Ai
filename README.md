# Qol AI

Мәтінді ым тіліндегі бейнеге айналдыруға арналған жоба. Қазіргі жария нұсқа — интерфейс прототипі; бейне генерациясы үлгі ретінде көрсетіледі.

## Әдістеме және модель

Жоспарланған тәсіл: мәтін → бейінді аударма сервисі → ым тіліндегі бейне. Мағынасы мен түсініктілігі сарапшылармен тексеріледі. Нақты модель мен провайдер әлі таңдалып, расталған жоқ; жеке оқытылған модель мәлімделмейді.

## Деректер және бастапқы код

[Бастапқы код](https://github.com/LofiSilent/Qol-Ai). Расталған оқыту деректер жиынтығы әзірге жоқ. Бағалау үшін қысқа хабарламалар мен сарапшы эталондары бар бөлек тест жиынтығы жоспарланған. Материалдарды пайдалану құқығы мен қатысушылар келісімі ескеріледі.

## Метрикалар және тест

Өлшенген нәтижелер әзірге жоқ. Жоспарланған метрикалар: дұрыс түсінілген хабарламалар үлесі, сарапшының мағыналық дұрыстық бағасы, аяқталған сұраулар үлесі және нәтиже алу уақытының медианасы.

Тест мысалы: «Кездесу ертең сағат 10:00-де басталады» мәтінін енгізіп, өңдеуді бастау. Қазір интерфейс әрекеті тексеріледі. Сервис қосылған соң бейненің ойнатылуы, уақыттың дұрыс берілуі және пайдаланушының хабарламаны түсінуі бағаланады. Сервис қатесінде түсінікті хабарлама көрсетілуі тиіс. Бұл — жоспарланған сценарий, орындалған сынақ есебі емес.

## Жетілдіру жоспары және TRL

Қазіргі нәтиже — пайдаланушы интерфейсінің прототипі; толық аударма циклі расталмаған. TRL деңгейі конкурс әдістемесі мен сынақ дәлелдері бойынша анықталады.

1. Провайдерді қосып, толық циклді бақыланатын жағдайда тексеру.
2. Тест жиынтығын бекітіп, сараптамалық бағалау жүргізу.
3. Мақсатты пайдаланушылармен пилот өткізу, қателерді түзету және TRL деңгейін қайта бағалау.
