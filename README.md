# Qol AI

Мәтінді ым тілінде көрсететін 3D-кейіпкер. Текст на языке жестов с помощью 3D-персонажа.

[Сайтты ашу / Открыть сайт](https://lofisilent.github.io/Qol-Ai/)

Қазіргі нұсқа — прототип. Текущая версия — прототип: позы рук условные, словарь жестов демонстрационный.

## Запуск

```bash
npm run dev       # локально из src/ → http://localhost:4173
npm run build     # сборка в dist/
npm run preview   # просмотр dist/
```

Сайт публикуется на GitHub Pages автоматически при пуше в `main` (`.github/workflows/deploy-pages.yml`).

## Структура

| Путь | Что внутри |
| --- | --- |
| `src/index.html` | разметка страницы |
| `src/styles.css` | стили |
| `src/js/main.js` | интерфейс: язык, тема, студия, примеры |
| `src/js/i18n.js` | тексты на ҚАЗ / РУС / ENG |
| `src/js/avatar.js` | 3D-персонаж: загрузка, камера, позы, проигрывание жестов |
| `src/js/signing.js` | текст → последовательность жестов |
| `src/data/gestures.json` | словарь жестов (формы руки и слова) |
| `src/assets/model/avatar.glb` | модель персонажа |
| `scripts/` | Telegram-бот и сборка |

## Как развивать

- **Новое слово:** добавить запись в `words` в `src/data/gestures.json`. Слова не из словаря пока показываются по буквам.
- **Новая модель (3D-скан):** заменить `src/assets/model/avatar.glb`. Если у модели другой скелет, поправить имена костей пальцев в начале `src/js/avatar.js`.
- **Настоящие анимации:** добавить клипы жестов в `.glb` и проигрывать их в `play()` (`src/js/avatar.js`). Интерфейс `textToFrames()` → `play()` при этом не меняется.
- **Новый язык интерфейса:** добавить блок в `src/js/i18n.js` и кнопку в шапке.
- **Тексты на странице:** у элемента атрибут `data-i18n="ключ"`, значение — в `src/js/i18n.js`.
