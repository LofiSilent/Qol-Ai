Отладочный ключ подписи для тестовых APK (пароль `android`, alias `androiddebugkey`, стандартные значения Android).
Он лежит в репозитории, чтобы каждая новая сборка ставилась поверх предыдущей.

Для публикации в Google Play нужен отдельный ключ релиза — его нельзя хранить в репозитории,
только в секретах GitHub (Settings → Secrets and variables → Actions).
